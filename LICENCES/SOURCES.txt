components distributed with the application and where their sources can be obtained.

3. Components installed later, not distributed with the application
-------------------------------------------------------------------

The application package contains no third-party code beyond the SDK files listed above.
The components below are downloaded on the user's machine, from their official sources,
when the user installs them. Each keeps its own licence; the Options tab of the
application and app/licenses.json list them, and the Installation tab shows the licence
of every model before it is installed.

Python packages (base runtime and AI engine), from PyPI:
    app/requirements.txt, app/requirements-engine.txt
    PyTorch: https://pytorch.org  (BSD-3-Clause)

Engine sources, fetched at a pinned revision (app/engine.json):
    M2D:                https://github.com/nttcslab/m2d                (NTT Software License)
    Omni-Embed-Audio:   https://github.com/JudeJiwoo/Omni-Embed-Audio  (MIT)

Model weights, fetched at a pinned revision with their checksum (app/models/catalog.json):
    M2D-CLAP:           https://github.com/nttcslab/m2d/releases
    LAION-CLAP:         https://huggingface.co/laion/clap-htsat-unfused
    Omni-Embed-Audio:   https://huggingface.co/JudeJiwoo
    Qwen3:              https://huggingface.co/Qwen
    CySearchAssist:     https://huggingface.co/cyberalien/CySearchAssist-CLAP-1.5B
                        https://huggingface.co/cyberalien/CySearchAssist-CLAP-0.5B
                        (Apache-2.0; their LICENSE and NOTICE are installed with the weights)

Some model licences restrict commercial use or require a personal acceptance; the
application never accepts a licence on the user's behalf. The MIT licence of the SDK
and the GPL licence of this application do not change the licence of any of these
components.
